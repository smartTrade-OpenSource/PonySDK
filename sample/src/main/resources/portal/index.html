Integrating PonySDK: the ways an existing system shows a PonySDK application.

Nine ways in

PonySDK applications are written in Java only: the screen's widgets live on the server, and a small terminal in the browser draws them. Such an application can own its page, or be shown by another system.

The application is the PonySDK showcase, on http://this-host:8081/sample/. This portal is another origin: each page below is the system that shows it, from the application owning its page to a page of another site holding applications of two PonySDK versions.

  1. U1

    Alone in its page

    The application owns the page: the bootstrap page its server writes, the default.

    For a whole application, with its own URL.

    Open the showcase
  2. U2

    A custom page of the application

    The application's own HTML around it, served by the application under its path: a header, a layout, then the widgets.

    For a branded page, with no other system involved.

    Open the custom page
  3. U3

    In an iframe

    Another document in a frame: nothing changes on either side, but the frame clips the popups, takes none of the page's styles and is sized by hand.

    For a system that only knows frames.

    Open the frame
  4. U4

    An element of another page

    <pony-app> in a page of another origin: two tickets and the showcase, each on its own context, in a shadow root. Attributes in, events out, both ways.

    For a portal or a web application of the same site.

    Open the portal
  5. U5

    In the page's document

    isolation="none": the application renders in the host's document, where addons that search it find it. The page's styles reach the application.

    For an application whose addons use the document.

    Open the page
  6. U6

    From another site

    No session cookie comes from a page of another site: the context's key and the host's credential replace it. Uploads, streams and reconnections work as on the same site.

    For a client's system, on its own domain.

    Open the portal on another site
  7. U7

    Several applications, one inside another

    A page holding several applications; and an application embedding another, which it drives from Java with PWebComponent.

    For a dashboard of applications, or composing them.

    Open the portal Open the Embedding page
  8. U8

    Windows and frames

    A ticket popped out in a window of its own, and a frame, from an embedded application: pages of the application, talking to the element by postMessage.

    For a trader's detached ticket.

    Open the page
  9. U9

    Two versions on a page

    The page defines <pony-app> with its own copy of PonySDK; each application runs on its server's terminal.

    For a portal of products on different PonySDK versions.
